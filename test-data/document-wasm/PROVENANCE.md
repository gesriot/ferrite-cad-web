All files originate from native FerriteCAD commit
`1b645299b206f3f87e9d3d9959428d2b245d6219`.

`native-plate.fcad` is copied unchanged from
`crates/ferritecad-fixtures/plate/plate.fcad`.

The other files were generated by that commit's CLI:

```sh
ferritecad create sample-small.fcad --sample --size 8 12 4
ferritecad create sample-fractional.fcad --sample --size 31.5 20.25 7.75
ferritecad create sample-inches-display.fcad --sample --size 50.8 25.4 12.7 --length-unit in
```

Sample generation creates fresh UUIDs/timestamps. Tests compare the committed
input bytes on both platforms, rather than expecting regeneration to match IDs.
